2  Estatística descritiva e visualização de dados no R

Você sabe como resumir, tabular e visualizar dados?

Depois de importar e manipular um banco de dados, o próximo passo é entender o que existe nele. Neste capítulo, vamos aprender a descrever variáveis qualitativas e quantitativas, produzir tabelas prontas e construir gráficos com o ggplot2 para publicações científicas e apresentações.

Ao final deste capítulo, você será capaz de resumir, tabular e visualizar variáveis qualitativas e quantitativas, produzindo tabelas e gráficos prontos para publicação científica.

library(tidyverse)
library(knitr)
library(gtsummary)
library(scales)
library(skimr)
library(flextable)
Pacotes utilizados

Caso algum pacote ainda não esteja instalado, execute apenas uma vez:

install.packages(c("tidyverse", "knitr", "gtsummary", "skimr", "scales", "flextable"))

2.1 Banco de dados dos exemplos: surto de intoxicação alimentar

Assim como no capítulo anterior, utilizaremos o banco surto, referente a um surto de intoxicação alimentar ocorrido durante um evento científico. A base contém informações demográficas, sintomas, alimentos consumidos e exames laboratoriais dos participantes.

# Lendo a base de dados
surto <- readxl::read_excel("./data/surto.xlsx",
                            sheet = "Plan1")

Antes de resumir os dados, vamos transformar as variáveis codificadas como números em fatores com rótulos compreensíveis:

surto <- surto %>% 
  mutate(
    caso = factor(caso, labels = c("Não", "Sim")),
    sexo = factor(sexo, labels = c("Feminino", "Masculino")),

    colica = factor(colica, labels = c("Não", "Sim")),

    nausea = factor(nausea, labels = c("Não", "Sim")),

    desidratacao = factor(desidratacao, labels = c("Não", "Sim")),
    febre = factor(febre, labels = c("Não", "Sim")),
    servsaude = factor(servsaude, labels = c("Não", "Sim")),
    gravidade = factor(gravidade, 
                       ordered = TRUE, 
                       labels = c("Leve", "Moderado", "Grave")),
    salada = factor(salada, labels = c("Não", "Sim")),

Também podemos criar a variável idade a partir da data de nascimento. Para isso, precisamos escolher uma data de referência. Neste exemplo, usaremos 20/11/2018, primeiro dia de início dos sintomas no surto.

data_referencia <- as.Date("2018-11-20")

surto <- surto %>% 
  mutate(
    idade = round(as.numeric(difftime(data_referencia, dtnasc, units = "days") / 365.25))
  )

2.2 Tipos de variáveis: classificação estatística e correspondência no R

Na estatística descritiva, o primeiro passo é identificar o tipo de variável. Isso define quais tabelas, medidas e gráficos fazem sentido.

Tipo estatístico Descrição Exemplo no banco Tipo usual no R
Qualitativa nominal Categorias sem ordem natural sexo, caso, agua factor ou character
Qualitativa ordinal Categorias com ordem natural gravidade ordered factor
Quantitativa discreta Contagem em valores inteiros número de sintomas integer ou numeric
Quantitativa contínua Medida em escala numérica hb, leuco, tgl numeric ou double
Data/hora Informação temporal dtnasc, dtisint Date, POSIXct ou POSIXlt
Por que isso importa?

Uma variável qualitativa costuma ser resumida com frequências e percentuais. Uma variável quantitativa costuma ser resumida com média, mediana, desvio padrão, quartis e valores mínimo/máximo dependendo de sua distribuição.

Além de resumir o banco, o summary() ajuda a identificar valores que podem estar incorretos. Por exemplo, se uma variável laboratorial apresentar um valor mínimo muito distante do esperado, devemos investigar se é um valor real ou um erro de digitação.

# Identificando a linha com o menor valor de leucócitos
surto %>% 
  slice(which.min(leuco)) %>% 
  select(id, caso, sexo, leuco)
id caso sexo leuco

No banco usado neste capítulo, o menor valor de leuco pode indicar um erro de digitação. Depois de checar a fonte original, podemos corrigir o valor no banco de trabalho. No exemplo abaixo, usamos a linha identificada anteriormente; por isso o código fica apenas como demonstração e não é executado automaticamente ao renderizar o capítulo:

surto <- surto %>%
  mutate(leuco = if_else(row_number() == 123, 6980, leuco))
Correção de dados

Nunca corrija um valor apenas porque ele parece estranho. Primeiro, confirme no prontuário, ficha de coleta ou fonte original. Se for corrigir, registre claramente o que foi alterado e por quê.

2.4 Introdução ao ggplot2: a gramática dos gráficos

O ggplot2 é o principal pacote do tidyverse para visualização de dados. Sua lógica é baseada na gramática dos gráficos: um gráfico é construído por camadas.

2.4.1 Camadas: dados, estética (aes) e geometria (geom)

As três partes essenciais de um gráfico no ggplot2 são:

Elemento Função Exemplo
Dados banco utilizado no gráfico surto
Estética mapeamento das variáveis aes(x = sexo, fill = caso)
Geometria forma visual do gráfico geom_bar(), geom_point()

2.4.2 A estrutura base de todo gráfico

A estrutura mais simples é:

surto %>% 
  ggplot(aes(x = sexo)) +
  geom_bar()

Nesse exemplo, sexo foi mapeado para o eixo x e geom_bar() contou automaticamente quantas observações existem em cada categoria.

O sinal +

No ggplot2, usamos + para acrescentar novas camadas ao gráfico, como geometrias, títulos, escalas e temas.

2.5 Introdução ao gtsummary: tabelas prontas para publicação

O pacote gtsummary produz tabelas de resumo com aparência adequada para relatórios, dissertações, artigos e apresentações.

2.5.1 O que é e por que usar na área da saúde

Em estudos em saúde, é comum apresentar a descrição da amostra em uma Tabela 1. Essa tabela geralmente inclui idade, sexo, sintomas, exames laboratoriais e outras características dos participantes.

O gtsummary facilita esse processo porque identifica automaticamente variáveis categóricas e contínuas, calcula estatísticas adequadas e permite personalizar rótulos, percentuais e casas decimais.

Média ou mediana?

A estatística {mean} ({sd}) apresenta média e desvio padrão. Para variáveis assimétricas, pode ser melhor usar {median} ({p25}, {p75}), que mostra mediana e intervalo interquartil.

2.7 Variável quantitativa: onde está o centro e quanta variação existe?

Variáveis quantitativas são medidas numéricas. No banco surto, exemplos são hb, leuco e tgl.

2.7.1 Média, mediana e moda: quando usar cada uma?

Medida O que representa Quando usar
Média Soma dos valores dividida pelo número de observações Distribuições aproximadamente simétricas
Mediana Valor central após ordenar os dados Distribuições assimétricas ou com outliers
Moda Valor mais frequente Útil quando há repetição de valores

A moda não tem uma função base tão direta quanto média e mediana. Podemos criar uma função simples:

moda <- function(x) {
  x <- x[!is.na(x)]
  valores <- unique(x)
  valores[which.max(tabulate(match(x, valores)))]
}
surto %>% 
  summarise(
    media_idade = mean(idade, na.rm = TRUE),
    mediana_idade = median(idade, na.rm = TRUE),
    moda_idade = moda(idade)
  )

2.7.2 Desvio padrão, amplitude interquartil e CV: summarise()

O desvio padrão mede a dispersão em torno da média. A amplitude interquartil é a diferença entre o terceiro e o primeiro quartil. O coeficiente de variação expressa o desvio padrão em relação à média.

surto %>% 
  summarise(
    n = sum(!is.na(idade)),
    media = mean(idade, na.rm = TRUE),
    dp = sd(idade, na.rm = TRUE),
    mediana = median(idade, na.rm = TRUE),
    q1 = quantile(idade, 0.25, na.rm = TRUE),
    q3 = quantile(idade, 0.75, na.rm = TRUE),
    iqr = IQR(idade, na.rm = TRUE),
    minimo = min(idade, na.rm = TRUE),
    maximo = max(idade, na.rm = TRUE),
    cv = sd(idade, na.rm = TRUE) / mean(idade, na.rm = TRUE) * 100
  ) %>% 
  kable(digits = 1)

Como ler um boxplot?

A linha dentro da caixa representa a mediana. A parte inferior e superior da caixa representam o primeiro e o terceiro quartil. Pontos fora dos limites podem indicar valores extremos (outliers).

```{r}
# Lendo a base de dados
```

## Tipos de variáveis: classificação estatística e correspondência no R

Na estatística descritiva, o primeiro passo é identificar o **tipo de variável**. Isso define quais tabelas, medidas e gráficos fazem sentido.

| Tipo estatístico | Descrição | Exemplo no banco | Tipo usual no R |
|---|---|---|---|
| Qualitativa nominal | Categorias sem ordem natural | `sexo`, `caso`, `agua` | `factor` ou `character` |
| Qualitativa ordinal | Categorias com ordem natural | `gravidade` | `ordered factor` |
| Quantitativa discreta | Contagem em valores inteiros | número de sintomas | `integer` ou `numeric` |
| Quantitativa contínua | Medida em escala numérica | `hb`, `leuco`, `tgl` | `numeric` ou `double` |
| Data/hora | Informação temporal | `dtnasc`, `dtisint` | `Date`, `POSIXct` ou `POSIXlt` |

::: {.callout-note}
## Por que isso importa?

Uma variável qualitativa costuma ser resumida com **frequências e percentuais**. Uma variável quantitativa costuma ser resumida com **média, mediana, desvio padrão, quartis e valores mínimo/máximo** dependendo de sua distribuição.
:::

Podemos verificar a classe das variáveis com `glimpse()`:

```{r}
surto %>% 
  glimpse()
```

::: {.callout-warning}
## Tipo de variável

Atenção: no R, nem sempre uma variável estará inicialmente no tipo correto. Por exemplo, números podem estar escritos como `character`.
:::

## Visão geral do banco: `summary()` e `skim()`

Antes de fazer tabelas específicas, é útil obter uma visão geral do banco.

A função `summary()` pertence ao R base e resume cada variável de acordo com sua classe:

```{r}
summary(surto)
```

Além de resumir o banco, o `summary()` ajuda a identificar valores que podem estar incorretos. Por exemplo, se uma variável laboratorial apresentar um valor mínimo muito distante do esperado, devemos investigar se é um valor real ou um erro de digitação.

```{r}
# Identificando a linha com o menor valor de leucócitos
surto %>% 
  slice(which.min(leuco)) %>% 
  select(id, caso, sexo, leuco)
```

No banco usado neste capítulo, o menor valor de `leuco` pode indicar um erro de digitação. Depois de checar a fonte original, podemos corrigir o valor no banco de trabalho. No exemplo abaixo, usamos a linha identificada anteriormente; por isso o código fica apenas como demonstração e não é executado automaticamente ao renderizar o capítulo:

```{r}
#| eval: false

surto <- surto %>%
  mutate(leuco = if_else(row_number() == 123, 6980, leuco))
```

::: {.callout-warning}
## Correção de dados

Nunca corrija um valor apenas porque ele parece estranho. Primeiro, confirme no prontuário, ficha de coleta ou fonte original. Se for corrigir, registre claramente o que foi alterado e por quê.
:::

Para uma visão mais organizada, podemos usar `skim()` do pacote `skimr`:

## Introdução ao `ggplot2`: a gramática dos gráficos

O `ggplot2` é o principal pacote do `tidyverse` para visualização de dados. Sua lógica é baseada na **gramática dos gráficos**: um gráfico é construído por camadas.

### Camadas: dados, estética (`aes`) e geometria (`geom`)

As três partes essenciais de um gráfico no `ggplot2` são:

| Elemento | Função | Exemplo |
|---|---|---|
| Dados | banco utilizado no gráfico | `surto` |
| Estética | mapeamento das variáveis | `aes(x = sexo, fill = caso)` |
| Geometria | forma visual do gráfico | `geom_bar()`, `geom_point()` |

### A estrutura base de todo gráfico

A estrutura mais simples é:

```{r}
surto %>% 
  ggplot(aes(x = sexo)) +
  geom_bar()
```

Nesse exemplo, `sexo` foi mapeado para o eixo x e `geom_bar()` contou automaticamente quantas observações existem em cada categoria.

::: {.callout-note}
## O sinal `+`

No `ggplot2`, usamos `+` para acrescentar novas camadas ao gráfico, como geometrias, títulos, escalas e temas.
:::

## Introdução ao `gtsummary`: tabelas prontas para publicação

O pacote `gtsummary` produz tabelas de resumo com aparência adequada para relatórios, dissertações, artigos e apresentações.

### O que é e por que usar na área da saúde

Em estudos em saúde, é comum apresentar a descrição da amostra em uma **Tabela 1**. Essa tabela geralmente inclui idade, sexo, sintomas, exames laboratoriais e outras características dos participantes.

O `gtsummary` facilita esse processo porque identifica automaticamente variáveis categóricas e contínuas, calcula estatísticas adequadas e permite personalizar rótulos, percentuais e casas decimais.

### Estrutura básica de `tbl_summary()`

```{r}
surto %>% 
  select(caso, sexo, idade, gravidade, hb, leuco, tgl) %>% 
  tbl_summary()
```

### Personalizando rótulos, estatísticas e casas decimais

Podemos controlar os nomes das variáveis, as estatísticas apresentadas e o número de casas decimais:

```{r}
surto %>% 
  select(caso, sexo, idade, gravidade, hb, leuco, tgl) %>%  # selecionar apenas as colunas das variáveis de interesse
  tbl_summary(
    label = c( # alterar o cabeçalho de cada variável para um nome mais condizente
      caso ~ "Caso de intoxicação alimentar",
      sexo ~ "Sexo",
      idade ~ "Idade (anos)",
      gravidade ~ "Gravidade",
      hb ~ "Hemoglobina (g/dL)",
      leuco ~ "Leucócitos (/mm³)",
      tgl ~ "Triglicerídeos (mg/dL)"
    ),
    statistic = list(
      all_continuous() ~ "{mean} ({sd})", # tipo de estatística a ser aplicada nas variáveis numéricas contínuas
      all_categorical() ~ "{n} ({p}%)" # tipo de estatística a ser aplicada nas variáveis categóricas
    ),
    digits = all_continuous() ~ 1, # número de casas decimais para as estatísticas contínuas
    missing_text = "Sem informação"
  )
```

::: {.callout-tip}
## Média ou mediana?

A estatística `{mean} ({sd})` apresenta média e desvio padrão. Para variáveis assimétricas, pode ser melhor usar `{median} ({p25}, {p75})`, que mostra mediana e intervalo interquartil.
:::

## Variável quantitativa: onde está o centro e quanta variação existe?

Variáveis quantitativas são medidas numéricas. No banco **surto**, exemplos são `hb`, `leuco` e `tgl`.

### Média, mediana e moda: quando usar cada uma?

| Medida | O que representa | Quando usar |
|---|---|---|
| Média | Soma dos valores dividida pelo número de observações | Distribuições aproximadamente simétricas |
| Mediana | Valor central após ordenar os dados | Distribuições assimétricas ou com outliers |
| Moda | Valor mais frequente | Útil quando há repetição de valores |

A moda não tem uma função base tão direta quanto média e mediana. Podemos criar uma função simples:

```{r}
moda <- function(x) {
  x <- x[!is.na(x)]
  valores <- unique(x)
  valores[which.max(tabulate(match(x, valores)))]
}
```

```{r}
surto %>% 
  summarise(
    media_idade = mean(idade, na.rm = TRUE),
    mediana_idade = median(idade, na.rm = TRUE),
    moda_idade = moda(idade)
  )
```

### Desvio padrão, amplitude interquartil e CV: `summarise()`

O **desvio padrão** mede a dispersão em torno da média. A **amplitude interquartil** é a diferença entre o terceiro e o primeiro quartil. O **coeficiente de variação** expressa o desvio padrão em relação à média.

```{r}
surto %>% 
  summarise(
    n = sum(!is.na(idade)),
    media = mean(idade, na.rm = TRUE),
    dp = sd(idade, na.rm = TRUE),
    mediana = median(idade, na.rm = TRUE),
    q1 = quantile(idade, 0.25, na.rm = TRUE),
    q3 = quantile(idade, 0.75, na.rm = TRUE),
    iqr = IQR(idade, na.rm = TRUE),
    minimo = min(idade, na.rm = TRUE),
    maximo = max(idade, na.rm = TRUE),
    cv = sd(idade, na.rm = TRUE) / mean(idade, na.rm = TRUE) * 100
  ) %>% 
  kable(digits = 1)
```

Também podemos calcular essas medidas por grupo. Por exemplo, média e desvio padrão da idade entre casos e não casos:

```{r}
surto %>% 
  group_by(caso) %>% 
  summarise(
    media = mean(idade, na.rm = TRUE),
    dp = sd(idade, na.rm = TRUE),
    mediana = median(idade, na.rm = TRUE),
    minimo = min(idade, na.rm = TRUE),
    maximo = max(idade, na.rm = TRUE)
  ) %>% 
  kable(digits = 1,
        col.names = c("Caso", "Média", "DP", "Mediana", "Mínimo", "Máximo"))
```

::: {.callout-note}
## Como ler um boxplot?

A linha dentro da caixa representa a mediana. A parte inferior e superior da caixa representam o primeiro e o terceiro quartil. Pontos fora dos limites podem indicar valores extremos (outliers).

O boxplot também ajuda a visualizar **posição** (mediana e quartis), **dispersão** (tamanho da caixa), **assimetria** (posição da mediana dentro da caixa) e possíveis **outliers**.
:::

```{r}
      idade ~ "Idade (anos)",
      hb ~ "Hemoglobina (g/dL)",
      leuco ~ "Leucócitos (/mm³)",
      tgl ~ "Triglicerídeos (mg/dL)"
    ),
    statistic = list(
      all_continuous() ~ "{median} ({p25}, {p75})",
      all_categorical() ~ "{n} ({p}%)"
    ),
    digits = all_continuous() ~ 1
  ) %>% 
  add_overall(last = FALSE)
```

O `tbl_strata()` permite criar tabelas separadas por estratos. No exemplo abaixo, a tabela é estratificada por sexo:

```{r}
surto %>% 
  select(sexo, caso, hb, leuco) %>% 
  tbl_strata(
    strata = sexo,
    .tbl_fun = ~ .x %>% 
      tbl_summary(
        by = caso,
        statistic = all_continuous() ~ "{median} ({p25}, {p75})",
        digits = all_continuous() ~ 1
      )
  )
```

```{r}
grafico_leuco <- surto %>%
```

### Exportando com `ggsave()`: formatos e resolução para periódicos

Depois de criar um gráfico e salvá-lo em um objeto, podemos exportar com `ggsave()`:

```{r}
#| eval: false

ggsave(
  filename = "figura_leucocitos_caso.png",
  plot = grafico_leuco,
  width = 16,
  height = 10,
  units = "cm",
  dpi = 300
)
```

Formatos comuns:

| Formato | Quando usar |
|---|---|
| `.png` | Relatórios, slides e documentos Word |
| `.tiff` | Submissão para alguns periódicos |
| `.pdf` | Gráficos vetoriais e documentos em PDF |
| `.svg` | Edição posterior em softwares vetoriais |

::: {.callout-tip}
## Resolução

Para publicação científica, uma resolução de **300 dpi** costuma ser o mínimo recomendado para imagens raster, como `.png` e `.tiff`.
:::

## Tabelas prontas para publicação

Além de construir tabelas, muitas vezes precisamos exportá-las para Word ou PDF.

### Exportando para Word com `as_flex_table()`

O `gtsummary` pode ser convertido em uma tabela do pacote `flextable`, que funciona bem em documentos Word.

```{r}
tabela_publicacao <- surto %>% 
  select(caso, sexo, idade, gravidade, hb, leuco, tgl) %>% 
  tbl_summary(
    by = caso,
    label = c(
      sexo ~ "Sexo",
      idade ~ "Idade (anos)",
      gravidade ~ "Gravidade",
      hb ~ "Hemoglobina (g/dL)",
      leuco ~ "Leucócitos (/mm³)",
      tgl ~ "Triglicerídeos (mg/dL)"
    ),
    statistic = list(
      all_continuous() ~ "{median} ({p25}, {p75})",
      all_categorical() ~ "{n} ({p}%)"
    ),
    digits = all_continuous() ~ 1,
    missing_text = "Sem informação"
  ) %>% 
  add_overall(last = FALSE) %>% 
  modify_header(label ~ "**Característica**") %>% 
  modify_spanning_header(c("stat_1", "stat_2") ~ "**Caso de intoxicação alimentar**")

tabela_publicacao
```

```{r}
#| eval: false

tabela_publicacao %>% 
  as_flex_table() %>% 
  flextable::save_as_docx(path = "tabela_publicacao.docx")
```

### Exportando para PDF via R Markdown

Para exportar uma tabela para PDF, uma forma prática é renderizar o próprio documento Quarto ou R Markdown em formato PDF. No cabeçalho YAML do arquivo, podemos usar:

```yaml
---
title: "Estatística descritiva e visualização de dados no R"
format:
  pdf:
    toc: true
    number-sections: true
---
```

::: {.callout-note}
## Word ou PDF?

Para edição, o Word costuma ser mais prático. Para submissão, impressão ou compartilhamento de versão final, o PDF preserva melhor a formatação.
:::
